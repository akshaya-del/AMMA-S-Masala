🌐 Go live (Google Sheet connection)

  1. Create a new Google Sheet → Extensions → Apps Script.
  2. Click Copy Google Sheet code below and paste it there (replace everything).
  3. In that code, change ADMIN_KEY to your own strong password.
  4. Select the function setup and click ▶ Run, then allow the permissions.
  5. Deploy → New deployment → Web app, Execute as Me, Who has access Anyone. Copy the URL ending in /exec.
  6. Open amma-shop.html in a text editor and paste the URL into const API_URL = "https://script.google.com/macros/s/AKfycbxmzBh3bmOkX1G0Gr2JqWxHPDWJpAsVbxd01x9ns_Wrsl_m3yrOV3634AFaik5QOhEThA/exec"; near the top of the script. Upload the file.
  7. Open yoursite/amma-shop.html#admin and log in with your ADMIN_KEY.
